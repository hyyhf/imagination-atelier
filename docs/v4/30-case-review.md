# 三十例本轮改动与仍有的差距

所有例均有实际文件改动，原领域模型不因新增版本册而被替换。以下是逐例完成边界，不是高分榜。

|作品|本轮反复操作的重点|仍需继续完成|
|---|---|---|
|01 光在小屋里|让同一间房，回答三种日光问题。|天窗光斑依然是简化几何示意；未升级为建筑光照仿真。|
|02 弯路，留一点余地|同一输入转速，两只车轮怎样分担。|机构仍是教学表达；未提供公差、受力或制造级齿轮接触模型。|
|03 山的里面|沿同一条岩层，追踪不同切口。|地层仍为合成模型；没有真实勘探数据的拟合工作流。|
|04 收一点|在几个相近的器形之间，真正作一次取舍。|陶器外观与壁厚、导出沿用原模型；烧成收缩和釉料工艺未建模。|
|05 一个原子的四周|同一个中心原子，从外部看到近邻内部。|晶格近邻几何不是量子化学；中心视角的真实触屏操作待验证。|
|06 把光送过去|把一次命中，变成能解释的光路。|几何光路不是波动光学；镜面有限口径与光束相交保留原算法。|
|07 路口的节拍|不给路口打分，先比较谁还在等待。|保留简化车流模型，不是校准过的实际路口配时系统。|
|08 字有天气|留住同一句话，试三种不同的天气。|文字海报的审美取决于内容、字体和构图；未对全部长文浏览器排版验收。|
|09 纸下水声|把“我选了这条路”与“它有证据”分开。|保留原有剧情、线索和判断；新增观察存档，不自动补写真相。|
|10 墙背后的小海|让一次空间探索，能在喜欢的地方停下。|空间叙事不新增剧情和世界规模；漫游碰撞与触屏仍需实机复验。|
|11 开店之前|同一个小店，把布置与材料一起推敲。|新增三维编辑和显示，但家具品类、建模细节、漫游与装修参考仍有差距；指针实际交互待验。|
|12 折成一份心意|礼物、纸张和闭合关系，放在一起比较。|依然是一个礼盒模型；纸张公差、印刷与实际折叠未进行实体测试。|
|13 一块板的余地|一块整板，到每一块真正要切的板件。|排料仍是启发式；承重、接合方式、工艺公差未作工程验证。|
|14 阳台的一季|在自己的阳台里，给一季生长留出余地。|种植数量与土量是几何估算；不预测产量或代替园艺诊断。|
|15 今晚一起开饭|从上桌时刻，倒排一场不慌张的晚饭。|多人数只按原算法换算食材；厨房执行时间仍需用户校准。|
|16 一堂课的导演|教案不是时长相加，还要真的在现场用。|恢复方案会按设计重置课堂计时；真实课堂计时与后台行为待验。|
|17 镜头先走一步|不移动机位，先看焦距改变了什么。|场景仍为简化人物道具；不能替代真实镜头畸变、照明和拍摄踩点。|
|18 线索成章|让每个研究结论，都有能回到的原文。|只整理已有资料与主题，不自动生成研究结论；没有新访谈全文内容。|
|19 出发前，装得下|先装进尺寸，再考虑怎么带着走。|箱体与物品仍用包围盒容量近似；衣物压缩和异形嵌套未建模。|
|20 把声音剪好|剪辑、配乐、淡出，都能回到上一种听法。|源采样完整保存；音频实际听感、设备延迟、浏览器解码和大文件性能未实测。|
|21 数据会说话|不只问曲线贴不贴，还要问它能不能预测。|统计推断仍限原有模型与假设；拟合好不代表因果或可靠外推。|
|22 曲面的下一步|走同一张曲面，用路径解释算法。|目标函数与优化器范围保留；只是固定函数实验，并非任意机器学习训练器。|
|23 轨道窗口|一次转移，用时间与速度代价一起衡量。|理想轨道转移，不作真实航天任务导航；本次未重做底层轨道算法。|
|24 让电路自己回答|让电路自己回答，再检查数值误差。|直流与RC暂态范围保留；不支持任意电子器件和实物安全校核。|
|25 一滴雨的去向|把高差、汇水与雨量的假设放到一张桌上。|雨量与汇水简化；不是洪峰、水位或风险预报。|
|26 把地球摊开|同一条路线，在不同地图里不该变长。|投影与球面地理简化；没有接入实时地图或专业GIS数据库。|
|27 一封数据包的旅程|带宽加倍之前，先找出数据包堵在哪里。|离散事件模型保留；协议栈、真实拥塞控制与网络实测未扩充。|
|28 像素的第二种生命|文件小了多少，和像素失去多少一起看。|PX8依然是自定义码流，不等于JPEG标准；大图真实交互待浏览器实测。|
|29 一句话的内部|把黑盒缩小，直到每一份权重都能保存。|小模型演示，非通用聊天模型；对照是相同权重的观察消融，不是假装重新训练。|
|30 答案之前，先找证据|先证明证据找对了，再谈怎样回答。|词法检索不等于远程大模型问答；证据和实验指标不替代人工相关性判断。|

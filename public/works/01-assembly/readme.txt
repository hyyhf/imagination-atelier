机械装配查看与资料制作

入口：index.html。解压后用支持 WebGL 的现代桌面浏览器打开。
运行资源已全部打包到这一份 HTML，核心操作不需要安装、命令行、服务器、账号或联网。当前会话只完成了 HTTP 浏览器验收；受会话安全策略限制，双击 file:// 与断网冷启动未实际验证。

开始：
1. 默认载入一套原创 WG-40 小型蜗轮蜗杆减速器，共 26 件零件。箱体透明帮助看见内部；可关闭透明、剖切、聚焦或隐藏零件。
2. 使用“新装配”，先在左下角选择导入单位，再导入自己的 STL、OBJ 或 GLB。STL/OBJ 的单位由你确定；GLB 常用米，通常应先选择 m。多个文件可一起追加，也可拖入工作区。
3. 点击模型表面或零件清单。修改名称、代号、分组、装配坐标、爆炸向量、材料说明、安装到、连接形式、步骤和备注，再点击“应用修改”；数值和短文本可用 Enter 应用。保存/生成资料也会应用当前属性。
4. G 开启拖动移动，R 开启拖动旋转；Esc 退出。拖动前自动合拢。精确坐标单位为毫米，旋转为度。局部尺寸根据真实网格和比例计算。
5. 拖动“爆炸展开”，或使用“按结构分散”作为可继续修改的初稿。展开不会覆盖装配坐标。“两点测量”在真实表面点选两点，结果来自三维坐标；这是表面点选距离，不是计量检验。
6. 填总说明后生成装配资料。资料 HTML 自含两张 1600×1000 编号图、完整清单、安装关系、步骤和备注；同事打开即可看，资料页可打印为 PDF。PNG 和 CSV 可另外导出。报告的图会临时关闭剖切，保证完整表达当前可见零件。

保留工作与下一套：
“保存项目”生成 .assembly.json，包含网格、内嵌颜色贴图、材质、名称、关系、步骤、备注、爆炸方向和镜头。“打开项目”恢复；它比图片更适合保存可继续编辑的装配。
“复制为下一套”保留完整装配与表达规则，再修改标题、另存。选某一零件“替换此零件模型”，保留身份、关系、坐标、步骤、备注及爆炸方向。替换后核对尺寸和位置。
“新装配”清空零件与总说明，保留显示偏好。关键操作可撤销/重做，Ctrl+Z / Ctrl+Y；大网格的历史步数会随内存预算减少。没有自动暂存，请主动保存。
浏览器下载若被阻止，保存和资料对话框提供完整文件原文，可以复制保存。生成反馈不表示已经覆盖或确认写入某个文件。

必要边界：
支持普通 ASCII/二进制 STL、OBJ 三角网格、静态且资源内嵌的 GLB。OBJ 的 MTL/外部贴图不读取；GLB 的基础颜色贴图会内嵌保存。法线、粗糙度等复杂贴图通道未保存。每个 OBJ/GLB 网格成为一件独立可编辑零件，原始 CAD 层级不自动映射为安装关系。
不支持 STEP/IGES 原生参数 CAD、GLB 动画/蒙皮、Draco/Meshopt/KTX2 压缩；请在 CAD/DCC 中导出普通网格。限制为 800 件/300 万顶点，单个导入模型不超过 80 MB，项目不超过 150 MB；大型模型建议先减面。
剖切为真实网格裁剪，截面不封口。安装关系用于组织资料，不求解运动学、碰撞、承载、公差或扭矩。零件坐标独立，设置安装关系不会自动带动下级。
原创示例以装配表达为目的，包含真实尺寸、开孔、螺旋、轴承滚珠、密封与连接细节；齿形和螺纹不是生产级加工曲面，非标准轴承代号不能直接采购。不能将资料当作经过工程认证的生产图。

许可：原创工具和模型采用 MIT；Three.js 0.170.0 的 MIT 许可见 LICENSES.txt。无远程字体、CDN 或账户依赖。用户导入模型的权利由用户自己的素材来源决定。

制作和验收资料：prompt.txt、record.txt、metadata.json、regression.cjs、source/、fixtures/、qa/。
这些是制作方资料；普通使用只需 index.html。面向使用者的 assembly-tool.zip 不包含 npm 依赖和开发源码。

光在小屋里
同一间屋，换一片天空。

入口
打开 index.html。运行所需的三维引擎、模型、材质、界面和文字都已嵌入这一个文件；没有外部字体、CDN、图片请求或安装步骤。review 文件夹是制作与验证记录，不是运行依赖。

先这样玩一会儿
1. 先看「一方天」：地面上的光被收成一块。
2. 点「一线天」：实际屋面开口变成长缝，光在地板上拉长，压条会留下分隔。
3. 点「一个圆」：真实圆形光井把投影修成另一种边界。
4. 稍微改变「日光高度」。光会向屋内或门边移动；较低的光线可能越过剖开的门边。把光线再升高，就能把光带回小屋。
5. 「看看天窗」可核对完整开口与厚度；「近看光影」可同时观察开口与地面投影；「视角复位」回到主构图。

操作
鼠标或单指拖动画面：旋转观察。
滚轮或双指距离：拉近、拉远。
画面右下的方向按钮与加减按钮：不用拖动也可以调整相机。
三个参数均有滑块和数值输入：开口尺度 70%—130%；前后位置 -1.15—0.30 米；日光高度 38°—78°。
天窗前后位置以房间中心为 0，负数靠后墙，正数向前。

键盘
1 / 2 / 3：更换方窗、长窗、圆窗。正在编辑数字时不会触发换窗。
用 Tab 聚焦画面后：方向键旋转，+ / - 缩放，Home 复位。
Tab 可依次访问按钮和输入；焦点有可见轮廓。

保留这一刻
「保存当前画面」从正在绘制的三维画布生成 PNG，并发起下载。它不使用预制宣传图。
页面会尝试在当前浏览器暂存天窗与相机状态。暂存可能因浏览器设置、清除数据、文件移动或路径变化失效；失败会显示文字提示。
在页脚展开「关于这间小屋与光」，可以恢复初始天窗与相机。

这间小屋是什么
它是为这个作品设定的三维观察模型，内部平面约 6.0 × 4.8 米，屋面中心高度 3.72 米，屋面厚 0.20 米。前侧与右侧部分墙体被剖开，方便看见内部。
默认方窗净开口 1.76 × 1.76 米；长窗 3.50 × 0.62 米；圆窗直径 1.85 米。尺度滑块会同步改变开口与木衬。
这是用方向光、真实遮光几何和投影阴影表达空间的实时近似。玻璃只做淡色透明表面，没有折射、透射率计算或路径追踪。它不输出建筑照度，也不代表某个真实地点的太阳路径。

实际验证范围
已从最终 index.html 抽取 scene-code，运行同一份 buildScene → Atelier3D.frame，通过原生 EGL/OpenGL ES 编译并执行同一套着色器与几何，生成 review/实际场景图 中的图片。已实际查看默认、换成长窗、圆窗近景、屋顶视角、低角度日光和窄幅场景。
已用独立的三角求交核对真正的挡光关系，也核对状态 JSON 往返、内嵌引擎一致性与无外链依赖。
本轮环境禁止浏览器与协议绕过。因此没有实际运行 DOM/CSS 布局、输入事件、localStorage、浏览器下载或 file:// 首次打开，也没有声称完成浏览器与移动设备兼容性验收。当前证据是同源三维场景渲染，不是整页截图。

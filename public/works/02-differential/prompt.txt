原始愿望：汽车转弯的时候，两个轮子为什么能转得不一样快？
使用技能：想象显影机 imagination-developer v3.0（冻结副本）。

把这个问题制作成一件可本地双击打开的单 HTML 三维机械解释作品《弯路，留一点余地》。核心命题是：外轮需要多走一段路，而中央小齿轮的自由自转，允许两个输出围绕同一个平均速度各快、慢一点。使用者先拨动“左弯”，亲眼看见两个相连输出的速度分开，再打开机构，理解行星齿轮既被壳架带着公转、又能绕横销自转。

做真正 xyz 几何、相机、光影的理想开式锥齿轮差速器教学试验架，不以两个孤立转轮或数字面板代替机构。主角占据宽屏中央大部分面积，轮轴从左右轮贯通至两颗相向的锥齿轮，两颗行星锥齿轮由可见横销支承在镂空载架中。载架有厚度、安装环、横梁、真实孔隙和螺栓；轮胎有断面、胎纹和轮辋，输出轴有转动标记。载架环作为已经通过主减速器的输入端，省略上游主减速器并说明。轮组、齿轮及载架有正确层级关系。教学核心放大，模型比例不冒充真实车辆尺寸。

艺术方向是暖黄色机械博物馆展台：浅蜂蜜色背景与地面、金属香槟色壳架、青蓝色左输出、朱红色右输出、深炭色轮胎、象牙色轮辋。高处侧光和柔和金属反射共同表达厚度；阴影把架体接回地面。避免霓虹、玻璃卡片、粒子、网格以及长入场动画。标题短，留给机械足够画幅。数字关系作为一条连续算式而非三张卡片，颜色与真实部件对应。辅助小平面弯道图解释内外轮路程，不取代三维主体。

主体验由转弯强度和载架转速两个参数驱动。直行时左右输出与壳架等速，行星齿轮相对壳架不自转；左转时左慢右快，右转时相反。相位由时间积分维护；编辑速度、转弯、暂停、换视角或展开时不能跳相位。设等大的两侧齿轮，ωL+ωR=2ωC；24 齿侧齿轮和 12 齿行星齿轮，行星在载架内的自转由齿数比推导。转弯由理想无滑动同轴双轮几何给出，物理轮距 1.6m、滚动半径 0.32m；输入速度范围 0–60 rpm，转弯强度 q=轮距/(2R)，限定 |q|≤0.65。明确外轮要走更长弧线；差速器允许这种速度差，不主动识别转向。齿面是可识别的示意建模，约束用运动学解析关系，不宣称齿面碰撞、牵引力或接触求解。

提供播放/暂停、少走一步、直行/左右弯、完整装配/内部观察/展开、相机左右上下与缩放、复位。拖动、范围控件都应有按钮或数值输入替代，键盘焦点可见；减少动态效果默认暂停，隐藏页面停止推进。视角和解释从同一状态生成。允许保存带版本、当前参数、相位、相机和解释结果的真实 JSON 快照以及重新导入；校验后原子替换，非法文件保持原状态。导出画面必须直接读同一实际画布，清楚报告能力失败。

使用 Atelier3D v1.0.1 全文内嵌，不运行时联网，不用模块、本地 fetch、CDN、安装或服务器。必须有不依赖 DOM 的 scene-code 脚本，暴露 SceneApp.initialState、advance、derive、buildScene、snapshot/restore；UI调用相同模型。制作方用 Node 从最终 HTML 提取内嵌引擎与 scene-code，经 A.frame 输出渲染包，再由共用原生 EGL 执行器渲染。真实审阅默认、左弯提速、内部与展开状态，保留必要同状态首版—终版图。最可能失败的地方是壳架遮住行星齿轮、锥齿轮轴向与相位不对、轮胎抢走主体、整机悬浮以及看不出自转/公转区别，发现后修改对应几何、镜头或层级，不能只调色。

交付 index.html、说明.txt、设计记录.txt、制作提示词.txt，以及 review 内实际场景出图、从最终HTML复现的脚本、独立机制检查及真实审阅记录。环境禁止所有浏览器本地文件及替代路线，因此不得使用浏览器、Playwright、CDP、HTTP预览服务器或 data URL；原生出图只能证明同源场景几何、着色器与渲染状态，不能宣称整页布局、DOM事件、file协议或性能已验收。专业机制需核对一手来源并在记录中注明。最后清楚区分冻结技能的创作/验证指导和共用引擎提供的渲染能力。

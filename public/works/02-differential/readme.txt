差速器观察室 · 02

入口
打开本文件夹内的 index.html。作品按普通单文件 HTML 编写，三维引擎、模型、样式和程序全部内嵌，设计为双击即可使用；不需要安装、构建、服务器或联网。运行需要支持 WebGL 的现代浏览器。单个 index.html 即是完整作品，review 文件夹是制作验证资料，不是运行依赖。

第一步
先点“左弯”：右轮成为外轮，转速增加；左轮靠内，转速降低。两侧始终满足：左轮转速 + 右轮转速 = 输入壳架转速 × 2。
然后点“看内部”，观察贯通中央的横销和它上面的两颗小锥齿轮。直行时它们只随壳架公转；转弯时它们还绕横销自转。“前进 0.1 秒”方便逐步看清动作。

怎样操作
• 完整装配：同时观察左右轮、半轴、侧齿轮与输入载架。
• 看内部：隐藏车轮和金色壳架，保留侧齿轮、半轴、横销与行星齿轮。
• 展开观察：左右输出组沿轴线退开；齿轮、半轴、轮组保持同组关系，中央行星机构保持原相位。展开后的零件没有接触，属于装配观察。
• 转弯强度：负值右弯、正值左弯、0 为直行；旁边显示该模型的中心转弯半径。数字框可直接输入。
• 输入转速：0–60 rpm。播放、暂停、换弯和调速都保留连续相位；“重置相位”回到初始观察相位。
• 拖动三维画面旋转，滚轮缩放；相机箭头、＋／−、复位按钮，以及画布上的方向键提供替代操作。
• 全部复位：恢复初始参数、相位和镜头。

怎样保留
“保存当前观察 .json”生成带格式版本的参数、相位、相机和派生结果快照。“载入观察”完整校验后替换当前状态，载入后暂停。未知版本、损坏、越界或不合法相机数据会被拒绝，当前观察保留。
“保存三维画面 .png”读取点击时的实际三维画布，不含页面文字和控件。按钮会生成下载；最终文件落盘仍取决于浏览器的下载行为。

模型的意义与边界
这是等大的两侧齿轮、24∶12 侧齿轮／行星齿轮比的理想开式差速器。金色壳架是经过主减速器后的输入，上游主减速器省略。道路计算假定轮距 1.6 m、滚动半径 0.32 m、轮胎不打滑；三维机械核心有意放大，画面比例不是车辆尺寸。
差速器允许两轮转速不同，并不会主动识别转向。本作品给定理想道路状态，以解析运动学决定转速和连续相位，没有计算齿面碰撞、惯性、摩擦、扭矩或轮胎打滑。齿面是有厚度的示意几何，不是可制造的共轭齿形。

已完成的验证
使用最终 HTML 内嵌的 scene-code 与内嵌引擎，在 Node 中导出真实几何、模型矩阵、材质、着色器与渲染参数，并用原生 EGL/GLES 渲染默认、左弯提速、内部、展开及首版同状态对照。实际查看了这些出图并修订。对转速关系、分段时间积分、四处节锥瞬时速度、展开变换、道路弧线、JSON 往返和非法导入进行了独立检查。

验证限制
制作环境明确禁止浏览器本地文件和替代绕行方式，因此没有使用浏览器、Playwright、CDP、HTTP 预览或 data URL。review 中的 PNG 都是同源三维“场景渲染”，不是整页截图。未实际验收浏览器 DOM 布局、事件、键盘/触控体验、file:// 首次打开、下载落盘、WebGL 兼容范围和帧率。减少动态效果、页面隐藏暂停、上下文丢失提示与窄幅相机适配已写入程序，但不把代码存在当作浏览器行为已被验证。

照片多规格裁切

入口：index.html。单文件，运行资源全部内嵌，不需要安装依赖或联网。
用桌面版现代 Chrome / Edge 打开即可使用。建议先处理 5–20 张，熟悉规格后再增加批量。

第一次使用
1. 点击“添加自己的照片”，或直接把 JPG、PNG、WebP 拖进页面。
2. 在原图上拖出完整主体范围；方图、竖图和横幅立即同步适配。
   尚未圈主体时会保留整个原图。比例确实容不下主体时使用所选底色留边，不假装识别或扩图。
3. 点击下方任一规格，拖动成图或用三个滑块单独微调。主体超出画面和像素放大会明确提示。
4. 右侧改尺寸、名称、留量和底色。这些规则对整批有效；单图单规格的调整会保留。
5. 点击“导出整套 ZIP”。每个规格一个文件夹，包含实际成图与检查清单 CSV。
   文件名包含序号、原文件名和宽高，重名原图也不会互相覆盖。也可单独下载当前规格。

继续使用
- 保存项目：JSON 包含原图片、主体范围、每规格微调和共用设置。以后“打开项目”继续编辑。
- 保存规格：只保存共用尺寸和输出设置，方便另一批照片复用。载入规格会重新适配现有照片，可以撤销。
- 开始下一批：清空本批照片，保留规格、底色、留量和格式。可撤销返回上一批。
- 25 步项目撤销 / 重做；一次拖动算一步。关闭页面前请保存项目，页面没有自动持久化草稿。

边界
- 手工圈主体，不是 AI 自动识别。真实物体完整性取决于所圈的范围。
- 只支持浏览器可解码的 JPG、PNG、WebP，不支持 RAW、HEIC、视频或动画。
- 所有成图均合成在所选实色底色上；不保留透明通道。原文件不修改。
- 单批最多 60 张；单张最多 30 MB / 5000 万像素；批次原文件总量约 150 MB。
- 最多 6 个规格；边长 32–6000 px，单张输出不超过 2400 万像素。
- 无生成式扩图、抠图、旋转矫正、批量主体识别或印刷色彩管理。
- 不保存原图 EXIF / ICC / 相机拍摄元数据，浏览器重新编码输出；色彩要求严格时请用专业软件复核。
- PNG 为无损编码，JPG / WebP 由浏览器编码。ZIP 只打包不二次压缩图片。

验证范围
已在原生内置浏览器的 HTTP 本地预览中验证导入、主体数值修改、多规格预览、微调警告、复位、检查状态、导出反馈和下一批。
已执行最终 HTML 内的真实逻辑，生成第一批 6 张 / 第二批 3 张的 ZIP；用独立 Windows 图片解码器核对第一批全部图片尺寸。
已执行含原像素的项目保存恢复、坏项目拒绝、换批次撤销；另附 CI 浏览器下载落盘及回导验收脚本。

山的里面
一座可以切开的山 · 独立单 HTML 作品

入口
打开 index.html 即是完整作品。所有图形代码、几何与材质都已内嵌，不需要安装、构建、账户或运行时联网。review 文件夹是制作与复现证据，使用作品不需要打开其中的脚本。

第一次可以这样玩
1. 点击“切到山心”。一刀会推进到 48%，山体正面移开，六层连续的岩带露出来。
2. 慢慢调整“切入深度”。观察同一层在不同切口里怎样接起来。
3. 转动“切面方位”，从另一方向读山；再把“地层起伏”降到 0，比较平直层面与弯曲层面的差别。
4. 点右侧某个岩层，沿着这一条带看。点“看全部岩层”回到完整配色。
5. 点击“保存这一刀”，生成当前切面的 SVG 矢量剖面。文件中还包含当前模型参数。

看近一点、回到开始
拖动山体可旋转，滚轮可缩放。画面下缘也有旋转、缩放和“主视角”按钮。“主视角”只恢复镜头；“重置”恢复全部初始参数。

键盘与数值替代
所有三个模型参数都有数值输入框。让焦点位于山体画布后：方向键转动视角，+ / - 缩放，[ / ] 改变切入深度，Home 恢复主视角。
“这座山怎样接起来？”内还有环绕角、俯视角与观察倍率的直接数值输入。

保留与恢复
“保存这一刀”：下载当前真实切口的 SVG，适合放大、阅读或打印；完整山体尚未切开时，此按钮不可用。
“保存参数记录”：下载 JSON，保存切入深度、切面方位、地层起伏、岩层选择和相机参数。
“读取记录”：读取本作品导出的 JSON。无效格式、未知版本或超范围数值会被拒绝，当前画面保留。
文件由浏览器处理下载；生成文件与浏览器是否已完成落盘是不同的事情。

这是什么模型
这是一座程序生成的虚构山体。六个岩性名称与色彩用于区分示意单元，不对应真实地点、年代、地层厚度或勘测结果。
山面与各层界共享连续的三角网格；切面与岩层的交线来自同一份几何。切口以真实的岩层三角面封盖，外壁和底部也封闭。
“地层起伏”是人为设定的空间参数，没有模拟真实成岩、构造运动或侵蚀过程。保存的剖面没有实际比例尺。

实际验证范围
已在 Node 中从最终 HTML 提取同一份无 DOM 场景模型，使用同一 Atelier3D 着色器、几何与状态生成原生 EGL/GLES 场景图。
已实际查看默认、切到山心、另一切面方位与最大地层起伏三种场景；已据此修订山形、坡面色阶、上部纹理与剖切后构图。
已核对几何封闭、切面面积、层界无缝连续、边界输入和 SVG/JSON 模型内容。

本轮没有使用浏览器。DOM/CSS 布局、实际事件与触摸行为、文件下载落盘、file:// 首次双击、浏览器无障碍表现与浏览器性能均未实测。review 中的 PNG 是实际场景渲染，不是整页截图。该边界不影响检查同一份模型及着色器的实际出图，但不能替代浏览器验收。

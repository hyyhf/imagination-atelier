制作日期：2026-10-10

一、输入与独立性
原始愿望仅为：“能不能切开一座山，看看下面的岩层是怎么接起来的？”
采用冻结技能：imagination-developer / 想象显影机 v3.0，来源为本轮 skill-source/imagination-developer/SKILL.md。已阅读 art-direction、spatial-3d、state-and-content、domain-verification、local-delivery、visual-review、prompt-output 参考。
没有读取 research、其他测试作品、其他 builder 的设计或评审。先形成并写下《制作提示词.txt》，再独立完成艺术指导、模型、界面、导出与评审。

二、创作命题与取舍
使用者亲手移开山体表面，得到的应是“连续岩层在山里面怎样接起来”的空间理解。
最能承载它的可见关系是：同一座山在完整和剖开状态之间变化，外部沟谷与内部连续层带共享同一条切口。

内部比较过：进入地下的漫游、把各层抽出来的抽屉式模型、直接剖开实体标本。漫游容易把注意力变成找路，抽屉式分解会把岩层之间的连续接触拆散，因此选用可连续推进的实体切面。保留相机与方位变化，让静态图片无法替代主要发现。

画面为矿物蓝空间中的山体标本。以椭圆形基座的实际岩体边界托住地形，不使用基础长方体堆叠。浅石色山脊与苔绿坡地形成外部轮廓，深蓝、青灰、石灰、铁红、灰紫和砂金组成六个内部单元。少量针叶树只用于提供坡地尺度。山体居于主画幅，控制在底部，岩层索引位于安静边缘。
动作无需持续动画。滑杆推进切口时，几何与解释来自同一状态；相机轻微向保留的岩体居中，以免切开后主角偏到一侧。

三、模型与真剖面
世界坐标为 XYZ，Y 向上；无实际距离单位或真实勘测含义。
地形基网格包含 144 个周向分段、44 圈径向分段，以 12,528 个三角面形成山脊、谷地和不规则椭圆边界。高度场组合三处峰体、连续脊线、分支坡脊和径向沟谷；高度差是实际顶点位移。

层界的共同起伏函数：
q = fold × [0.60 sin(0.82x + 0.28z) + 0.15 cos(z - 0.40x)]
从底部到上部的边界高度为：
[-1.08, -0.62+0.15q, -0.06+0.38q, 0.53+0.64q, 1.16+0.82q, 1.80+q]
上部砂岩延伸至地表；为其细纹定义了位于所有地形之上的参考高度 5.20+q，避免细纹错误追随侵蚀后的地表。所有岩层先在源网格顶点取值，再在同一三角面内线性插值。不同层界并不交叉。

切面法向由方位角决定：n=[sin φ,0,cos φ]。保留 dot([x,0,z],n) <= distance 的部分。切入深度为 0 时保持完整；非零时 distance=support×(1−2×depth)。上限为 88%，保留可观察的山体。
逐源三角形裁切真实山面与封底。切线和外围边界在每个层界与地表的交点处分段，按准确的上下边界生成岩带封盖；剖面法线指向被移开的部分。不存在依赖片元裁剪留下空壳的实现。外壁、底部、山面与切口组成几何封闭的整体。
SVG 直接投影同一组剖面多边形与细纹三角形，图例使用相同颜色计算，并嵌入点击时的参数记录。JSON 回导在完整校验后才替换状态。

四、首版观察与实际修订
首版 HTML 保留为 review/v1.html；对应真实场景为 v1-default.png、v1-cut.png、v1-oblique.png。三张均由最终架构的 SceneApp → A.frame → 原生 EGL 路线生成并实际 view_image 审阅。

首版已成立：完整山体能作为主角，剖切真正暴露连续的六层岩带；切口和岩层外壁有厚度与遮挡，另一方向仍是同一座山。
最弱部分：峰顶偏圆钝，宽大浅色坡面内容不足；坡面五级配色在三角形边界过于突兀。上部砂岩的细纹插值错误地以地表作为上参考，出现追随山顶的弧线。

已做的修订：
1. 重写峰体衰减，让峰顶更锐利，并加入两组实际径向沟谷；不是用颜色遮盖圆钝几何。
2. 将五级坡面颜色改为九级连续矿物色阶，综合高度与坡度分配，缩小相邻色阶差。
3. 上部细纹改为基于独立连续层界，并在山面交点准确截断。
4. 切开后镜头轻微居中并收紧距离，使保留岩体持续占据足够画幅。
5. SVG 补入同一组层内细纹，聚焦某层时导出图例与色带同步。

修订后的同状态证据为 v2-default.png、v2-cut.png、v2-oblique.png。最终文件又经小范围几何边界修复后，重新导出 final-default.png、final-cut.png、final-oblique.png；这三张是最终交付 HTML 的实际场景，均再次 view_image 检查。最终切到山心时有 2,998 个封盖三角面；另一方位有 2,269 个。山体和内部色带的连接清楚可辨，沟谷能在斜侧面读到。

五、独立判据发现的边界问题
核对使用边界法向面积向量闭合、封闭曲面体积与山面柱体积分一致、独立源网格交线积分面积、逐竖线覆盖与交线顶缘误差。
在 depth=0.50、azimuth=0°、fold=0 的网格对齐切面中，首次检查发现闭合向量残差约 1.041。原因是浮点正负零让四段相同切线得到不同字符串键，生成重复封盖；仅检查体积会漏掉它，因为切面经过坐标原点。
现已用整数坐标量化统一正负零并去重。保留了这个针对性的网格对齐状态，修后与其余边界状态一同通过；没有通过放大容差回避问题。

最终六组模型核对覆盖：完整、山心、44°斜切与起伏1.30、0°平层网格对齐、88%切入与−80°方位、1%切入与80°方位。
观察到的最大闭合向量残差约 1.95×10^-13；封闭体积与柱体积分最大误差约 1.50×10^-12；剖面面积最大误差约 3.56×10^-14；交线顶缘最大误差约 4.45×10^-16。41条竖向抽样线在各切面中无可见间隙与重叠，所有封盖朝向正确。上下限起伏下的最小内部层厚约0.314模型单位。数值只证明此虚构模型的几何一致，不证明真实地质机制。
真实最终报告见 review/model-check-report.json。参数记录往返一致，未知版本、越界值与缺失/无效值被拒绝；导出的 SVG XML 可由独立解析器读取，记录元数据与快照相符。

陶器3D器形设计工具
一只矮胖花瓶的练习

怎么打开
双击 index.html，在启用 WebGL 的现代浏览器中打开。全部几何、材质、字体回退、界面和渲染代码都在这个文件里；不需要安装、不需要服务器、不需要联网。其他文件只是制作与检验证据，不是使用前提。

第一次可以这样捏
1. 默认已经选中「口」。把下方「这一圈的宽度」滑杆往左移一点，或握住瓶口两侧的小把手向中间拖动。
2. 点击「原形对照」，在同一镜头下看最初的开口；再点一次看现在。右侧的小轮廓会同时保留起形与当前形。
3. 点「看瓶口」检查圆唇与内腔，或拖空白转动观察。滚轮、＋／−按钮都能近看、退远；「归位」回到起始镜头。
4. 喜欢了就点「带走这只」，给它起个名字，保存陶谱或照片。

能改变什么
「口、肩、肚、足」只是把手的位置，不是造型预设。还可以直接点住左右轮廓中的其他高度再向里收或向外推。「局部捏」影响较窄的一段，「柔和推」会带着附近的泥一起变化。
高矮和泥壁可以连续调整。赤陶、铁釉和米釉具有不同的表面粗糙度与光泽。收口时外壁、圆唇、内壁一起重建。
圈宽的 100% 以最初起形时的最大腹宽为参照；右边的「现在的口 / 肚」则是当前器形的宽度比。所有尺寸都是这间小室的相对比例。

撤回与保留
一次连续拖动是一笔操作。撤回／重做会恢复造型、泥料和名字；观察视角不进入塑形历史。重新起坯也可以撤回。
浏览器会尝试暂存，但暂存受浏览器设置和本地路径影响。请保存 JSON 陶谱作为可以恢复的副本。下次先打开 index.html，再在「带走这只」里打开陶谱，或直接把陶谱文件拖到页面上。

四种带走方式
陶谱 JSON：保留可继续塑形的半径、器高、壁厚、泥料、名字与观察视角。
照片 PNG：保留点击导出时的真实三维画面和一行作品信息，不保留编辑能力。
轮廓 SVG：当前经线轮廓与最初起形的矢量对照稿，附当前比例。
立体形 STL：真实闭合厚壁网格，使用相对单位，不包含泥料颜色。
导入会先验证文件；损坏、未知版本和超范围数据不会替换当前陶坯。

键盘与设备
Tab 可以逐一到达控件，方向键调整滑杆。画布获得焦点后，方向键转动视角，＋／−缩放。⌘／Ctrl Z 撤回，Shift 加同一组合重做。触屏可用单指拖轮廓或转动，滑杆与按钮提供相同的主要能力。
如果浏览器没有 WebGL 或三维上下文中断，页面会说明情况；已有陶谱仍可保存。页面不持续自动转动，隐藏时停止多余绘制。

制作与检验范围
这是一件器形与比例练习作品，不是烧成、承重、生产或打印工艺校核。
已经用最终 HTML 内的实际 SceneApp 与 Atelier3D 代码执行模型、历史、回导与导出检查；默认、收口、俯视内腔、米釉结果四个状态通过原生 EGL／OpenGL ES 重放了同一套几何、着色器与参数，并逐张审阅。
本轮按环境约束没有使用浏览器。因此 review/ 中图片是「场景渲染」，不是整页截图；真实浏览器 DOM 排版、触控与键盘事件、下载对话框、PNG 浏览器导出、file:// 首次打开及不同浏览器／GPU兼容性，均未实际验收。实现了相关路径和失败提示，但不把源码检查当成浏览器实测。

建议先试：把口 / 肚从约 56% 收到 45% 附近，再慢慢寻找你喜欢的分寸。

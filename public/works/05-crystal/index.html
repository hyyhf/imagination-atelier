THE GEOMETRY

数的是位置，不是光点

这个作品用理想单组分面心立方（FCC）点阵观察空间关系。整数坐标 i、j、k 都在 −4 到 4 之间，且 i+j+k 为偶数，共 365 个位置。位置写作 (i,j,k)·a/2，最近中心距 d=a/√2，在作品里归一为 1。

最近邻由当前原子到片段内所有原子的实际三维距离求得。面、棱、角少掉的邻居在这个截出的有限片段之外；空圈只是理想晶格的续接提示。退去外层、按层观察，都不会删改原子数据。

按 [010] 方向区分上 / 同层 / 下，并非按屏幕的上下来分。邻居间细线勾出第一邻域，外层细骨架连接相距 1 d 的可见位置；金色径向线表示中心距，均不表示化学键。FCC 内部 12 近邻关系参考 IUCr · 2023。

CHOOSE A POSITION

也可以指定一个原子

输入整数坐标。和为偶数的位置才属于本模型。你也可以直接点三维场景中的原子，跳到它的局部环境。

数字键 1 / 2 / 3 切换晶格、近邻与进入；方向键转动，＋ / − 调整视野，R 复位。也有对应按钮。进入后，相机位于中心原子的位置，该球暂时隐去；用方向键或拖动转头寻找各个方向的邻居。

“记下此刻”下载可恢复的观察 JSON，包含选中位置、显示设置与真实近邻表。“恢复观察”读取你选择的文件。数据只在本地使用。

A DELIBERATE MODEL

球有形，原子没有这层壳

球的大小、色彩和光泽是显示语言。半径 0.50 d 时，同一距离上的理想等球刚好相切；外层以小球显示是为了露出内部。模型不描述电子云、电子结构、作用能、晶体缺陷、热振动或真实实验数据，也不对应某一种具体材料。

“表面”是本作品沿传统立方坐标面截出的片段表面，8 / 5 / 3 是指定面、棱、角选址在这个有限点集中的计数，不能推广成所有晶面的通用答案。

页面中的三维图形需要 WebGL。作品不加载外部资源，帮助中的资料链接仅在你主动打开时联网。共享绘图资源：Atelier3D 1.0.1。观察逻辑、模型、镜头、界面和此处文字均在本 HTML 中。

晶格近邻与原胞3D观察
晶格里的三维观察作品

打开
直接用现代浏览器打开 index.html。运行时无需安装、构建、账户、服务器或网络资源；三维显示需要 WebGL。本次环境禁止浏览器，因此“本地双击”的依赖条件已从代码检查，但没有冒充实际 file:// 首次断网打开验收。

第一次这样看
1. 在“01 晶格”中，金色原子是你的站位，钴蓝球是它的第一近邻。外层退成浅色的三维骨架，朝你的一角被隐藏，以便看见内部。
2. 点“02 近邻”，让上下文退出。按“上层 / 同层 / 下层”逐层观察，再点“全部”。方向是晶格的 [010] 方向，不是屏幕的上下。
3. 点“03 进入”，视点到达中心原子的位置；占据该位置的金球暂时隐去。拖动或用方向键转头。默认朝向 [111] 附近，先看到三位近邻围出的空隙。
4. 换成“表面”“棱”“角”，计数会重算为这个有限片段内的 8、5、3。空线圈是片段之外的理想续接位置，不计入当前近邻。
5. 把球的显示半径拉到 0.50 d，查看理想等球相切的状态；也可以缩小球，使中心距线和遮挡关系更易看清。

操作
- 拖动：外部轨道观察 / 进入后的转头。
- 方向键或方向按钮：转动视角；Canvas 需要先获得键盘焦点。
- 滚轮、＋ / − 键或按钮：改变视野。
- 数字 1 / 2 / 3：在 Canvas 获得焦点时切换晶格、近邻、进入。
- 点可见实心原子：到该原子的位置重新查看。
- 页面下方整数坐标输入：精确选择 i,j,k。范围均为 −4 至 4，且 i+j+k 必须为偶数。
- “复位”或 Canvas 中的 R：恢复最初的站位、半径、分层、显示选项和镜头。
- “记下此刻”：生成真实观察 JSON，含当前参数、选中原子、近邻表、相对位置、中心距、分层和缺邻位置。
- “恢复观察”：只读取你选择的观察 JSON。坏文件、未知版本、非法参数不会替换当前有效状态；读取期间发生新的用户操作时，旧读取结果不再覆盖它。

模型与数字
本模型采用理想单组分 FCC 几何点阵：
  i,j,k ∈ {-4,-3,…,4}，i+j+k 为偶数；共 365 个位置。
  世界位置为 (i,j,k)/√2；最近中心距 d=1。
  传统立方晶胞边长 a=√2 d；界面坐标用 a/2 为单位。
  实际近邻判定：与当前原子的欧氏距离等于 1，容差 10^-7。

预设位置与实际计数：
内部 (0,0,0)：12 = 上4 + 同层4 + 下4；缺邻0。
表面 (4,0,0)：8 = 上3 + 同层2 + 下3；缺邻4。
棱上 (4,4,0)：5 = 上0 + 同层2 + 下3；缺邻7。
角上 (4,4,4)：3 = 上0 + 同层1 + 下2；缺邻9。

这些值来自坐标距离查询，界面没有按站位名称硬编码答案。外层剥离、分层按钮和相机只改变显示，不改变整个有限点集。界面“显示数量”指参与场景显示的近邻数，仍可能因视角被遮挡或落在视野外；它不是屏幕像素的可见数量。

解释边界
球的颜色、光泽和大小都是显示语言，径向线与外层细骨架不是化学键。0.50 d 是理想等球的几何相切半径，不是真实原子的锐利边界。这个作品不描述电子云、电子结构、能量、热振动、真实缺陷或实验数据，也没有指定真实材料。8 / 5 / 3 是本作品传统立方坐标面截取的特定有限片段结果，不是所有晶面的通用数值。

已经做过的验证
- 从交付 HTML 中提取纯脚本，独立核对全部365个原子的邻接、已知边界例、距离、层分解、缺邻位置、选取射线、状态保存/回导和几何变换。
- 从同一 HTML 的 buildScene 导出 A.frame JSON，由原生 EGL/GLES2 执行原样着色器、几何和 uniform，生成 review 下的实际场景 PNG。
- 已用 view_image 查看默认、第一近邻、进入、面/角边界、另一俯视的上层4点、相切半径，以及首终版同状态图，并据此修改几何表现与镜头。
- 最终标准场景为1600×790。首版和同状态比较为1600×1000。它们都是场景渲染，不是DOM整页截图。

没有做过的验收
环境严格禁止浏览器、Playwright、CDP、预览服务和绕过协议。没有验收实际DOM/CSS整页布局、真实指针/触屏/键盘事件、file:// 首次断网打开、下载对话框、辅助技术或浏览器GPU兼容性。代码提供了响应式排版、键盘/按钮替代、WebGL失败说明与上下文丢失处理，但这些浏览器行为只经过源码检查，不称已实际操作成功。

制作实际可用的「CSV 表格批量清洗工具」，交付自包含 index.html，用户双击即可按设计使用，不安装、不登录、不启动服务。固定并打包成熟 Papa Parse，保留许可，不使用 CDN、远程字体或运行时模块。

用户带入 CSV/TSV 或从表格软件复制的含列名内容，多文件可合并。支持 UTF-8、GB18030/GBK、UTF-16 LE 与明确分隔符；格式错误、重复列名、行列不匹配整体拒绝，不破坏旧作品。原值始终是字符串，编号前导零和引用中的换行、引号、逗号不丢。

规则真正按顺序执行，可添加、编辑、启停、移动或拖排，针对指定字段，提供首尾空白、大小写、查找替换、数字提取、精确十进制数值、指定格式日期、拆出新列、合并字段、按键去重、筛选隔离、校验与参照表关联。金额不得用二进制浮点冒充十进制舍入，测试 1.005、2.675、负数、零以及超出安全整数范围的大金额。日期要验证真实存在，不自动猜格式。新列不得覆盖原列，重复参照键必须选择明确策略。

中间工作表从同一有效状态显示原始、结果、问题和隔离；统计、搜索、分页与导出范围一致。点击问题行能同时定位来源、原记录、原值、处理值与具体错误。人工修正保存在独立覆盖层，重跑规则，保留原值；可以恢复或手动隔离。原始记录与重复并到哪个记录可追踪。

真实导出 CSV/TSV、问题与隔离清单、处理 HTML 报告。默认仅导出校验通过记录，可明确改范围；筛选显示不暗改导出。可选公式保护，说明与编号列类型的区别。完整方案 JSON 含源表、规则、修正、隔离、参照表与设置；校验后原子恢复。规则文件可跨任务复用，下一批清空旧材料与人工修正而保留并匹配规则，缺字段步骤停用提示。支持合理撤销/重做和异步过期读取保护。

用独立门店表完成第一次导入、校验、纠错、原值追踪和导出；保存/打开方案，再换第二批保留规则，核对没混入旧修正。保留含前导零、引用换行、金额与重复的 fixture。终端 VM 回归直接读取最终 HTML 内嵌模型，独立判据验证十进制、CSV往返、日期、重复关联、非法方案、恢复与第二批。实际 Browser 只通过 UI 操作与只读 DOM/已写入的剪贴板取证，不读取隐藏应用状态。下载落盘无法核实时明确留给 CI，VM 预期文件不得冒充浏览器下载。file:// 被策略禁止时不绕过，离线冷启如实标未验证。

CSV 表格批量清洗工具
====================
入口：index.html。全部运行代码与 Papa Parse 5.7.0 已内嵌；按设计可双击使用，无需安装、账号、服务器或 CDN。本次仅在本地 HTTP 实际验收；file:// 被会话安全策略禁止，离线双击冷启动未验证，未重试或绕过。

第一次使用
1. 点「导入 / 粘贴」，选择 CSV / TSV 或粘贴含列名的表格。文件支持 UTF-8、GB18030/GBK、UTF-16 LE；多选可合并。首次可清空规则，也可按同名字段匹配现有规则。列名应唯一。
2. 点击左侧规则编辑处理字段。支持首尾空白、大小写、替换、数字提取、精确十进制数值、日期、拆分、合并、按键去重、隔离筛选、校验和参照表关联。顺序会影响结果，可上下移动或拖排。
3. 金额按十进制字符串计算，半数向远离零的方向舍入；1.005→1.01，2.675→2.68，-1.005→-1.01。编号不会自动转数值，前导零保留。不要给编号列误用「规范数值」规则。
4. 中间切换清洗结果、待复核、隔离或原始视图，点「查看 / 修正」。右侧同时显示原值与处理值，修正提交后重新运行规则，原始记录不被覆盖。可以恢复原值或手动隔离。
5. 默认仅导出通过校验的记录，隔离清单和处理报告另有按钮；搜索和分页不会改变导出范围。CSV 真实引用逗号、引号和换行。Excel 公式保护会给潜在公式前缀加引号，纯数据管道需要时可关闭。
6. 点「保存方案」下载完整 JSON，保留所有源表、原值、规则、人工修正、隔离、参照表和导出设置。「打开方案」可恢复；重要结果请保存文件，浏览器暂存不是长期备份。

继续下一批
「下一批，保留规则」清空当前材料、修正和手动隔离，保留规则与输出选择；新表导入后重新启用能匹配的原规则。缺字段的步骤会停用并提示，需手动重新映射。
「保存规则 / 载入规则」适用于把规则与参照表给另一批材料，完整方案用于恢复当前任务。撤销/重做保留最近 35 次提交，包括规则、导入、修正和下一批。

独立示例与验证
fixtures/batch-a.csv 含前导零、引用换行、引号、正负舍入、大金额、重复记录与错误日期/邮箱。
fixtures/batch-b.csv 是独立第二批；可检查规则复用后两条有效记录、零金额和重复隔离。
fixtures/qa-plan.json 是从实际 HTML 模型在终端 VM 生成的可恢复第一批方案，用于浏览器文件恢复检查。expected-* 文件也由 VM 模型生成，明确不是浏览器下载文件。
fixtures/browser-first.tsv 与 fixtures/browser-second.tsv 是点击真实「复制结果 TSV」后从剪贴板读取的第二批结果。
preview.png、preview-first.png、preview-second.png 为实际 HTTP Browser 截图。regression.cjs 读取当前 index.html 的内嵌模型进行 59 项独立回归，不依赖制作模块；最终用户无需运行。

边界
每任务最多 10000 行、120 列，每份输入最多 10 MiB，方案最多 25 MiB。支持 CSV/TSV，不直接打开 XLSX。日期遵守用户选择格式，不猜 DD/MM 与 MM/DD。金额的分组逗号须合法。
CSV 文本中的编号前导零保留；Excel 直接双击 CSV 仍可能自行推断数值，应按文本列导入编号。公式保护与编号列类型不是同一种功能。
按步骤校验，修改规则顺序会影响异常的发现与去重结果；参照键重复时须选明确策略。当前没有远程数据库、AI 语义纠错或业务真实性判断。
本次验证保存/导出按钮和文件回导；下载默认目录的实际落盘交后续 CI 核实。没有读取浏览器隐藏状态或存储；暂存按钮未作内部数据检验。

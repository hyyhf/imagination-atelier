《字有天气 / TYPEWIND》专属制作提示词
依据：imagination-developer v3.0。用户任务：「能不能把我这几句话做成一张可以玩的海报？」当前没有给定原句；下面的英文诗句是本次编辑的可改示例，不冒充用户原文。

请直接制作一件完整、可双击打开的单文件 HTML 作品。目标不是参数编辑器，而是一张让人用手势给文字施加压力、得到自己的构图的可玩海报。创作命题：语言原本排得整齐，一次轻微的外力会留下无法重复的姿态。用户改句子、在纸面拖动，亲手感受「同一句话也有不同天气」。

选择二维 Canvas 字体绘图。字就是主体，三维不会增加本题的表达。输出竖向 4:5 海报，橙红色纸面、浅奶黄色巨大紧排字、深靛蓝风痕。正文占画幅约七成。大字按显式换行排版，每行按真实字宽适配；短句和长句有不同伸缩张力。顶端只有一行微小印刷标题，底端以细线、手势方向标记和一行短句收束。纸面微颗粒是印刷材料线索，不能用发光、粒子或装饰网格取代字形表现。

示例文字精确使用：
SOME WORDS
NEED
MORE
AIR.

核心动作是「按住拖动起风，松手定格」：按下点决定局部风压中心，拖动向量决定方向和力度；同一个有界连续变形场驱动字的基线弯曲、位置、倾斜和轮廓余迹。风痕必须从当前字形和当前向量派生。静止时不自行运动，不添加没有因果的动画。给一组经过编辑的「吹一阵」动作，方向键能调整风，Shift+方向键移动施力位置，避免只会拖拽的人才能使用。一次拖动形成一次撤回。提供「平息」恢复无风排版，同时保留用户文字；提供撤回，支持比较和探索后复位。

页面围绕海报组织，不做侧栏和卡片面板。纸面上方是小标题「字有天气」和「改一句话」入口；纸面下方是一行直接动作和保存入口。文字编辑像打开一张小字条：有明确标签、换行说明、即时预览和完成按钮。允许 1—6 行，每行不超过 24 个可见字符、总计不超过 100 个可见字符，支持中英文。空输入和越界输入给明确原因并保留最近有效作品，禁止把无效新输入误称已应用。编辑保留当前的风。中文使用用户设备系统字体回退；此次渲染环境无中文字库，实际评审必须使用英文示例并写明中文未做字形验收。

保留作品的两个出口都取点击时快照：2400×3000 PNG；一个仍可双击继续玩的完整 HTML，内含当前文字与风的状态。图片与可继续编辑的文件从同一状态和同一 draw 函数生成。HTML 中安全序列化状态，不把文字直接拼成代码。成功提示应是「已生成文件 / 浏览器将保存」，不得保证下载已经落盘。导出时不能混入编辑控件或手势提示。

全部运行资源内嵌，无构建、服务器、CDN、fetch、邻接文件依赖。使用合法的现有 DejaVu Sans Bold 子集作为拉丁字形，将字体数据与完整许可放入 HTML；中文界面回退系统字体。默认关闭无必要动画，主要操作可键盘完成，焦点可见，窄屏时纸面保持比例，控件自然换行。页面隐藏时不继续绘制。

将不访问 DOM 的绘图和状态模型放入 HTML 的 <script id="artwork-core">，导出 globalThis.Artwork，至少包含 initialState()、draw(ctx,width,height,state,timeSeconds)、状态验证及序列化/恢复函数。真正页面调用这个 draw。UI 脚本独立。

禁止任何浏览器、HTTP 服务器、Playwright、CDP 或用 data URL 绕过浏览器限制。用 Node @napi-rs/canvas 直接执行成品 artwork-core，保存默认场景、一次主要操作后场景，以及结果导出核对。它们明确称「Canvas 场景渲染」，不称浏览器截图。重跑脚本从最终 HTML 提取核心及内嵌字体，不另写宣传图。实际查看图片，若字形拥挤、风痕淹没正文、极端操作使内容出界，应修正后再渲染。核对真实像素改变、文字编辑继续保留风、导出状态复读后像素一致、错误数据不替换有效状态。

仅写入指定的 08-typewind 目录：index.html、制作提示词.txt、说明.txt、设计记录.txt，以及 review/ 中实际渲染和可重跑脚本。不要读取其他作品或方向简报。最后说明实际看过和未测试的范围。

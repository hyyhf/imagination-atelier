墙背后的小海
一处可以慢慢走进去、再从原路回来的三维小地方。

入口
打开 index.html。全部运行资源已经放在这个文件里，不需要安装、构建、账户或网络下载。页面需要浏览器提供 WebGL；无法启动时会显示清楚的说明。

第一次怎么走
点「沿贝壳慢慢走」，它会带你沿实际石路走到下一个停留点。再点可以继续，也可以随时点「停在这里」。穿过拱门后向右，绕过圆孔廊和背风处，再走进墙后的小院。

自己探索
• W / S 或上下方向键：向前、向后。
• A / D 或左右方向键：转身。
• 鼠标或单指拖动画面：环顾。Page Up / Page Down：抬头、低头。
• 右下方向按钮可按住使用，也可用键盘 Tab 选中后按住空格或 Enter。
• Esc：停下辅助行走；打开说明或手记时用于关闭。

路上可选的停留
到圆孔附近可以「回头看圆孔」，到石凳附近可以「坐一会儿」。这些不是收集要求，可以直接继续往里走。

到了池边
靠近倒扣的白陶，点「轻轻翻开」或按 E。可以留下看一会儿，再选「沿原路回去」。重开后会开始一次新的散步；「从头走」也会清空这一次的手记和发现。

保留与声音
这是一件短散步作品，没有声音依赖。手记只留在本次打开的页面中，不写入浏览器暂存，也不把临时状态当作长期备份。主要成果是走过并发现的体验，不需要文件保存操作。

实际验证范围
已从最终 HTML 中取出原文引擎与无 DOM 场景模型，在 Node 中实际走完辅助行走、看孔、坐凳、翻船与往返路径；检验了墙、池、海的不可走区域，以及故事只叙述本次实际经过的事。
已把同一模型、几何、GLSL 着色器和参数导出为 A.frame，经原生 EGL/GLES 执行，获得默认、门内、圆孔、坐姿、池边、翻船后、回程和窄画幅 PNG，并实际查看。全部交付 PNG 完整解码通过。
这些图片是「同源场景渲染」，不是浏览器整页截图。此次环境禁止浏览器、Playwright/CDP、file://、HTTP 服务器及替代协议，因此没有测试真实 DOM/CSS 排版、浏览器事件、文件双击冷启、下载、具体 GPU/手机兼容或浏览器 FPS。相关代码与静态结构已检查，实际设备行为仍有上述边界。

作品：开店之前 / BEFORE OPENING
原始愿望：我想把一个小空铺排成周末快闪店，看看怎么放才顺手，还能拿走采购与布置清单。

制作一个自包含的中文 HTML 快闪店布置工具。用户打开看到已布置的 6.2 × 4.6 米周末杂货店；直接改成自己的房间、入口与家具尺寸。命题是“先把每一件东西安放到尺寸里，再让空间真正站起来”。采用带采购账本的纸面平面图，配合同一状态的真实三维店面。纸白、砖橘、深蓝黑，地毯和木作有具体质感；不用通用数据仪表盘。默认含货架、挂衣架、陈列桌、台座、收银台、长凳与绿植，三维细节体现各自用途。

用 mm 保存几何。二维可选中、拖动、贴墙、50 mm 网格吸附；亦有数值位置、宽深高、90°旋转和方向键替代。对象可新增、复制、删除、更名、改单价。房间长宽高、入口宽度和位置、自定义净空提示阈值可编辑。2D / 3D / 双视图切换；3D 是真正的几何、投影、遮挡、光影与轨道观察。房间尺寸四周标注，显示实际占地和总费用，采购按相同类型/尺寸/单价合并数量。

对矩形占地独立求越界、重叠、入口占用与小于用户阈值的轴向间距。把它明确称为布置提示，不给消防或通行合规判断。二维清楚标记问题，点击提示选择对象。新建可用空房间，示例可恢复。重要文档变化撤销重做，一次拖动一条历史，文本输入不被全局快捷键抢走。

导出带尺寸、对象编号、清单和提示的 SVG 布置图，以及采购 CSV；完整方案 JSON 可回导，严格验证文件版本、单位、全部类型、数值范围与唯一 ID 后替换。暂存失败不影响手动保存。全部资源内嵌，不要求安装、联网、服务器或账户。WebGL 不可用时保留二维与全部数据操作。绘制按需，隐藏页停绘，失去上下文与卸载清理资源。

将模型、Canvas 图面、3D 场景与 DOM 控制拆分；建立无 DOM AppModel 与 SceneApp、Artwork 入口。用同源实际绘图取得默认、编辑、导出与边界画面，亲自查看后修主要缺口。检查已知矩形间距/重叠、汇总、实际 SVG/CSV、完整方案往返与非法载入。无浏览器条件不冒称整页或真实事件验收。交付单 HTML、使用说明、真实设计记录、适量证据。

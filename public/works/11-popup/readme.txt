开店之前 · 快闪店布置工作台
============================
双击 index.html 使用。资源全部内嵌，无安装、账户、运行时网络或服务器要求。默认是一间 6200 × 4600 mm 的原创周末小店；价格为可修改示例。

先试一次：拖动中央陈列桌到入口前，看到红色提示；撤销后把桌宽改为 1600 mm，再添加一个台座，修改单价。采购账本即按同类型、尺寸与单价合并数量。切换 3D 看同一方案的体积和遮挡。

自己的方案：可点“空房间”，设置长宽高、入口宽和入口中心距左坐标，再逐件添加。所有位置是家具中心，X 从左墙计，Y 从后墙计；旋转以 90°为单位。物件尺寸以本地宽深为准，旋转后的占地会自动交换宽深。拖动可贴墙和吸附 50 mm 网格，数值、方向按钮和键盘均可替代。画布焦点下，方向键每次 50 mm，Shift + 方向键 10 mm。

带走结果：保存方案 JSON 可完整恢复可编辑数据；布置 SVG 带尺寸、编号与采购汇总；PNG 为同源平面图；CSV 为采购账本。SVG 标注 mm，但版面并非 1:1 打印纸样。浏览器暂存只作便利，请用方案 JSON 保存重要进度。“恢复暂存”会作为一次可撤销操作。

范围：只处理矩形房间、一个前侧入口和最多 80 件矩形占地家具，家具旋转为 90°倍数。间距是矩形在一个轴投影重合时另一轴的最短空隙，非可通行路径；入口 900 mm 为本工具示意区。这里不做消防、载重、装修施工或无障碍合规判断。道具商品不在采购数量与费用中。

验证：用实际 HTML 的 AppModel、Artwork 和 SceneApp 核对面积、已知矩形、费用、方案往返、非法输入拒绝、空房与较小房间；实际生成 SVG/CSV 后分别用 XML 与 CSV 读取器回读。同源图面与实际着色器场景经过原生渲染和查看。没有进行浏览器整页、真实鼠标键盘触屏、首次断网双击或移动设备验收。WebGL 不可用仍保留二维编辑、清单与方案操作。

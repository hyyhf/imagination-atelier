开店之前 · 实际制作与修订记录
==============================
使用冻结的想象显影机 v3.2；原始一句话愿望见制作提示词。场景制作、交互接线与模型核对是制作方贡献；共享 Atelier3D 1.0.1 原样内嵌，承担投影、着色、阴影与轨道控制，不提供家具成品。

1. 创作选择
桌面像一张可以拿到现场的布置工单：二维是操作主入口，三维把抽象尺寸变成具体货架、衣服、陶器、收银终端和绿植。砖橘陈列台、暖木和深绿金属让店面有内容。采购放在同一张工作单下方。默认 8 件家具，已有清楚入口与主体桌面；保留 2 处小间距提示，让提示如实报告，不把示例伪装成合规方案。

2. 首轮实际图面
review/before-default-3d.png 与 before-default-plan.png 是真实首轮；before-index.html 是当时文件。查看发现木纹抢过模型轮廓，盆栽被收银台遮挡。降低木纹强度，将盆栽移至入口左边，使整个盆器与叶形在默认镜头可辨。修订后的默认、核心操作与结果已原生出图并实际查看。

3. 边界修订
把房间缩小到 3000 mm 宽的有效输入后，原图面仍只按房间取景，部分越界家具被裁掉。二维和 SVG 改用房间与全部家具的联合范围，越界家具继续可见并标红；三维复位镜头也包含它们。拖动期间冻结取景范围，避免越界触发自动缩放造成指针漂移，释放后更新。另把入口附近的选中尺寸标签移到家具上边，避免压住入口标注。二维明确显示当前需复核数量。

4. 模型与输出
已独立核对 6.2 × 4.6 = 28.52 m²、默认费用 5520 元、编辑后费用 5750 元；已知旋转矩形与 100 mm 空隙/重叠、贴墙中心位置、空集合、缩小房间的越界提示。JSON 完整往返派生结果一致；重复 ID 与无效数值拒绝且原状态不变。实际导出 SVG 被 XML 解析、CSV 被独立解析合计。最终 PNG 全部完整解码，哈希见 image-integrity.json。

5. 尚未实机确认
同源 Canvas 图面与 native A.frame 几何/GLSL 不是网页截图。DOM 布局、鼠标键盘触屏事件、下载对话框、本地 file:// 首次断网与移动设备性能尚未实机验证。没有以检查数量证明审美或可用性。

最后事件与结果路径复查：增加独立文件读取代次，最后选择生效；编辑、取消或隐藏令旧读取失效。实际从最终 HTML 提取异步文件处理函数，用可控文件 Promise 核对两个读取的完成顺序、编辑和取消；没有称其为浏览器事件验收。pagehide 共用幂等资源清理，pageshow 的历史缓存返回重新初始化观察器、渲染器和轨道控制。Canvas 按 CSS 逻辑尺寸绘制以保持高 DPI 标签字号，并真实查看 360 CSS px / 2x 同源 Canvas 图，调整了窄画幅标签与页脚分行。

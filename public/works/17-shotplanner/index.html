模型、保存与使用说明

几何透视视角由传感器尺寸和焦距计算，3D 模型不会推算真实镜头畸变、景深、灯光曝光或演员动作。播放为按时长硬切镜头。PNG 接触表包含每个真实取景、主要参数和备注首行；完整备注在 CSV 与 JSON 中。

重要编辑可撤销 / 重做。暂存可能受浏览器或路径限制；请使用 JSON 保存长期备份。载入先验证再替换，错误保留当前方案。自定义对象位置可能超出工作室，不自动解释成可行布景。

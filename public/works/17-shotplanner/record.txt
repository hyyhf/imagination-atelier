17｜3D分镜与机位预演
制作依据：想象显影机 v3.2 起始快照；用户原始愿望与完整任务流程。制作前提示词保存在同目录。

选择：采用摄影机监看台的深炭灰、暖珊瑚色镜号和双视图。默认剧情仅作镜头编排线索，不伪称真实拍摄计划。3D 的价值是机位、焦距、遮挡与对象位置共同改变最终画面；2D 更适合迅速摆位。固定工作室配长桌、空椅、纸张、杯子、书架、窗框、植物、木箱、吊灯，人物用可缩放的整体造型和关节表达朝向。

真实首轮 review/before-default.png、before-action.png、before-result.png 与 before-index.html 保留。实际查看发现：默认镜头地板留白偏多；人物躯干由盒体与椭球叠加，胸部有生硬接缝；俯视中心多张完整文字标签互相挤压。
修订：缩短并降低默认机位，重新设定目标与焦距；重建连续旋转剖面躯干，加入眼睛/鼻子使注视方向可辨；俯视先画家具后画人物，未选对象使用编号，只有当前对象显示全名，对象列表对应编号。变化由实际几何与绘制路径完成，不另造宣传图。

最终实际查看：default/action/result/edited/overview PNG；contact-sheet.png 是实际三个机位输出与网页同一 contact() 排版路径；plan.png 为网页同一 draw() 俯视核心。中文图面使用网页内嵌子集的等价 OTF 核对，未用缺字替身。已核对单文件脚本语法、导出的 CSV 在 Python csv 中回读，以及图片完整解码。

重要模型边界：普通透视 FOV = 2 atan(sensorHeight / (2 lens))；sensorWidth / sensorHeight 决定画幅。完整三维视锥来自相机坐标基；二维俯视扇形仅标为水平视角示意。播放是依时长硬切。相机与目标禁止重合或竖直重合以避开 up 向量退化。输入最多 60 个道具、30 个镜头。下载内容取点击时完整快照。

共同资源贡献：Atelier3D 1.0.1 提供同源几何、材质、阴影、相机投影与渲染器；Noto Sans CJK SC 字体支持中文图面。场景、数据模型、全部流程、编辑与导出为本次制作。不是盲测，不把机制核对数量换算为审美评分。

尚未验证：DOM/CSS 的浏览器实排、真实拖动/键盘/触屏、首次 file:// 冷启动、具体设备 WebGL 兼容性与帧率。原生 GLSL 执行和画面查看不替代这些边界。

2026-10-11 独立交叉审查后的定向修复
spatial 审查指出三个实际控制路径问题：空舞台复制在检查选中之前 clone(undefined)；pagehide 释放资源后没有 pageshow 恢复；文件读取可在拖动预览中途替换对象数组，后续移动或取消引用旧对象。另发现窄屏单独限制监看高度会改变竖画幅的实际宽高比。
修复：复制先检查源对象，空选中时复制/删除按钮禁用，直接调用也返回明确提示；拖动开始、移动、结束/取消、隐藏页废弃独立读取代次，新载入先取消当前预览，提交/撤销也清理拖动，释放捕获前先清空 drag，迟到 pointerup 不会反写旧文档；pagehide 取消绘制请求并保存总览相机，pageshow 重建渲染器和 Orbit，恢复画面与导出按钮；窄屏由同一传感器比例计算限高后的宽度并居中，监看框使用 content-box 保持画布比例。
定向证据 review/interaction-lifecycle-check.cjs / .json 从最终 HTML 抽取实际控制函数，以普通数据容器和注入效果执行顺序：空舞台复制无异常无修改、正常复制；旧文件读取在移动期间完成后被废弃，下一次移动仍安全；取消恢复拖动前文档；新文件在拖动中开始读取时先取消预览，载入后迟到 pointerup 不覆盖新文档，撤销快照仍是移动前方案；页面隐藏使读取失效；pagehide/pageshow 控制分支重新安排绘制并保留文档/总览相机。注入的 Renderer/Orbit 用于观察创建、释放和调度效果，没有声称真实浏览器或 WebGL 恢复已运行。宽高约束另用 5:80、9:16、16:9、80:5 比例进行独立算术核对，未声称 DOM 尺寸已实测。
本次只改已知交叉审查风险对应的 UI 与监看约束；AppModel、SceneApp 和 Artwork 图形/计算核心未改。原有实际 PNG 内容与哈希不变，无需重造效果图。最终 HTML 已重建、全部脚本语法核对，最终哈希在 review/final-integrity.json。

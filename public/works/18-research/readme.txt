访谈摘录整理与主题分析｜本地研究墙

双击 index.html。默认是明确虚构的“社区借物”研究示例：5 位参与者、5 份完整访谈、14 条摘录、3 个主题，还有相反证据与待归类材料。

开始自己的工作：
1. 点“新项目”，在“参与者与标签”添加参与者代号和背景，在“来源册”粘贴原始文字。
2. 点“新摘录”，填写原话、定位、自己的解释、主题、立场、标签与相关证据。逐字匹配检查引文是否完整出现于所选来源；不符合时保留卡片并标为待复核。
3. 卡片可以拖到别的主题，也可在编辑窗口用选择框移动。拖动改变主题会把立场置为“待判断”，避免把原来的支持关系不加思考搬过去。
4. 主题摘要和下一步问题由你撰写。来源、参与者、标签、主题都可维护；带引用的来源/参与者受删除保护。删除主题会把卡片送回待分类，删除标签不会删除卡片。
5. 搜索、标签和参与者筛选仅改变墙面显示；导出的报告与 PNG 是完整项目。界面明确显示当前可见数量和项目总数。

带走结果：
- 研究报告 HTML：完整主题摘要、支持/相反/待判断证据、解释、相关证据跳转、原始来源全文，可以单独打开与打印。
- 研究墙 PNG：全部主题的实际图面，长引文/解释会标记省略，全文在报告中。过大图面会明确拒绝，建议输出 HTML 报告。
- 证据 CSV：含参与者、来源原文、定位、摘录、解释、主题、立场、标签。使用模板同名表头整批载入；标准引号、逗号、换行均解析。标签用 | 分隔。
- 项目 JSON：包含稳定 ID、来源、全部关系、摘要与内容，是完整可编辑备份。CSV 不代替 JSON，因为不保存摘要和证据间的链接。

撤销 / 重做覆盖项目编辑、整批 CSV 导入与 JSON 载入。暂存可恢复但可能受浏览器或路径限制；重要工作请手动保存 JSON。非法数据整体验证后才提交，失败保留原状态。CSV 同名参与者还需描述相同才复用；来源标题/参与者/日期/全文全部相同时复用，其余视作新材料。

内容边界：这是人工研究整理工具，不调用 AI、不按关键词伪造研究结果。“支持”是研究者的标注，“逐字匹配”只是引用文本核对。摘录计数与去重参与者计数不同，也都不能推出人群比例。原始示例完全虚构。

全部运行资源随 HTML 内嵌。Noto Sans CJK SC 覆盖默认材料和界面的子集随文件，许可见字体许可.txt；其余用户字符通过设备字体回退。

已核对：自己的参与者/来源/卡片/摘要编辑、来源变化后的匹配、去重计数、删除保护、JSON 一致回读、带换行和引号的 CSV、坏文件整批拒绝、报告全部锚点与原文、实际 Canvas 默认/操作后/结果/长内容图面与完整 PNG 解码。没有进行浏览器整页、真实输入事件、设备字体回退或首次 file:// 双击验收；原生图面不是网页截图。

项目规范 JSON 总量上限为 12 MB。编辑、批量导入与保存使用同一实际 UTF-8 大小边界，因此本工具接受并导出的完整 JSON 可通过自身载入上限。超过总量的修改会在提交前拒绝，可将材料拆成多个项目。

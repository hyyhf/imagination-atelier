把一段声音，整理成作品。

直接点播放可以试听原创合成示例；用“导入自己的音频”换成录音或音乐，再编辑与导出。

一段完整的工作流程

  1. 导入音频后，素材自动加入当前轨道。也可在素材架重复放入主音轨或衬底轨。
  2. 点击片段选择；拖中间移动，拖两端裁切。下方参数可以精确设定原音起止、摆放位置、音量与淡化。点击“应用片段参数”生效。
  3. 点击时间尺定位，分割片段、增删标记，试听混音或只听所选片段。分割会保留原淡化曲线，后续淡化可叠加，也可点击“重设淡化”重新设置。
  4. 保存完整方案 JSON 继续编辑；导出 WAV 得到可播放音频，PNG 与 CSV 留下剪辑结构。

快捷键

空格 播放/暂停；← / → 移动播放线，按住 Shift 加快；Alt + ← / → 移动所选片段；Ctrl/Cmd + Z 撤销，加 Shift 重做；Delete 删除所选片段。编辑文字时这些快捷键不抢占输入。

保存与范围

重要修改请保存完整方案。小方案会尝试完整暂存；大音频方案不会只保存一个缺失声音的壳。浏览器可能拒绝暂存，或在换路径后找不到它。时间线最长 180 秒，最多 16 个片段；全部源采样另有 48 MB 上限，保证完整备份可再次载入。内置示例为原创程序合成，峰值显示为采样峰值，不是响度测量。单、双声道 PCM WAV 可直接读取，其他格式由浏览器解码。关闭或隐藏页面时暂停。

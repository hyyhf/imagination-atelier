数据拟合比较与反向标定
离线实验分析工作台

给带着一组测量数据的人：不用先整理成固定列名，也不用在不同软件之间拼接曲线、异常清单和报告。在一张工作台上完成导入、比较、核查、预测与带走结果。

打开
双击 index.html。核心资源、字体与数据全部内嵌，不需要安装、注册、服务器或网络。数据留在当前浏览器中。

先做一次有价值的操作
默认是一组明确标为合成的传感器标定观测，包含一条待核查记录。
1. 点击图上的第 8 条观测，或“观察疑点”中的残差列表，看到它对应的原始读数与偏差。
2. 只有确认采集或实验条件有问题时，才把这条记录改为“保留原记录，排除计算”。原数值不会消失；三个模型、残差与预测一起重算。撤销能返回修改前。
3. 看三模型同屏比较：较小训练误差未必带来较小留出误差。点选其中一个模型，让预测与报告使用你的选择。
4. 输入电压预测浓度，也可以输入目标浓度反查电压。二次曲线可能有两个解，范围外的解会标为外推。
5. “带走分析报告”生成可离线阅读、打印或保存 PDF 的 HTML，包含曲线、模型比较、原始观测、逐点结果与方法假设。“保存实验”生成能继续编辑的 JSON。

换成自己的数据
点击“导入 / 粘贴数据”。可以选 CSV / TSV 文件，也可以从 Excel 复制包含列名的矩形区域。
先预览，再选择 x、y，以及可选的观测名称、sigma 与用途列。列名不必叫 x、y；轴名称会采用你选中的列名，单位在导入时填写。确认后一次性替换观察记录，可以撤销。空数字、非法角色、重复列名、缺列或超范围数据会具体报错，当前有效实验不被覆盖。
不提供用途列时，全部作为训练点；可以随后“每 5 行留出”，也可以为重要观测逐点指定用途。已有排除不会被这项批量留出操作清掉。

输入范围
最多 200 行、512 KiB。x、y、正推 x 与反查目标 y 在 ±1,000,000 内；sigma 在 10⁻⁹ 至 10⁶ 内。角色使用 train、validation、exclude。支持逗号、制表符、分号，以及英文双引号包裹的逗号和换行。这里不替你插补缺测或悄悄丢行。

怎样理解比较
有留出点时，比较原始 y 单位的留出 RMSE；留出点从未参与拟合。
没有留出点且样本足够时，对训练点逐一移除、重拟合、预测被移除点，给出留一交叉验证 RMSE。它比只看训练误差更有信息，但不等于独立新实验。数据不足时会明确显示不可比较，绝不以训练误差冒充验证误差。
界面不会替你自动决定最佳模型。请结合残差结构、实验机制、数据量与应用范围。最低误差不能证明因果关系或外推正确。

科学约定
直线 y=a+bx；二次 y=a+bx+cx²。指数在 ln(y) 中拟合 ln(A)+bx，参与点必须 y>0；它拟合的是条件几何均值，不能自动当成算术均值。
普通最小二乘假设误差独立、同方差；误差方差用 SSE/(n−p) 估计。加权法把 sigma 当作已知响应标准差，权重为 1/σ²，协方差不按残差缩放。两者都假设 x 误差可忽略。
指数的 sigma 是 ln(y) 标准差，另外两种是原始 y 标准差。加权比较时，同一个 sigma 数字并不代表相同误差假设，界面和报告会提醒。
图上误差条是输入 1σ；残差浅色区是用户设定的绝对偏差检查线；二者都不是置信区间。超过检查线不代表观测必定错误。参数与均值标准误不包括系统误差，也不是新观测的预测区间。

保存与继续
JSON 保存原始数据、用途、单位、模型、权重、预测 x、反查目标 y 与检查线；旧版版本 1 实验 JSON 可继续读取。完整实验与方案册接口保持兼容。
HTML 报告是点击时同一份实验快照，能够离线打开；PNG 只包含图面。CSV 分别提供原始数据、逐点结果和系数。浏览器暂存可能被清理，重要资料请保留 JSON 文件。
最近 40 次编辑可以撤销 / 重做。新选择或新编辑会使旧的异步文件读取失效，迟到的文件不会覆盖你的新决定。

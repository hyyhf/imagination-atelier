# 方案对照与版本册

不是每件作品都需要版本册。需要反复调整、可解释地比较方案时：

- 从当前权威状态生成对照，写明变化项和固定项；不另造一套好看的默认数据。
- 每个版本保存规范化原始参数与必要素材，指标重新计算；显示派生数据不能成为唯一恢复源。
- 改动通过原作品事务接口，保留本来的校验、取消、撤销语义。一次应用是一笔操作；失败不能半提交。
- 执行重算前让页面反馈工作状态。小模型／大图片／长音频要明确容量预算；停止和换输入使旧任务失效。
- 比较同一数据集时使用同一划分、随机条件、时间范围；不同样本必须标出来。
- 用户命名和注释按文本转义；禁止将导入 HTML 当可执行内容插入。
- 大文件按 UTF-8/序列化后的实际字节检查。导出和导入容量一致；超额保留现有数据，提供减少版本或分开保存的路径。
- 媒体数据、模型参数与优化器需要实质恢复验证；只有缩略图不算备份。
- 故事、观察与研究可以保存路径和证据，但不能擅自生成答案、替研究者判定主题正确。

界面可共享，领域适配不能共享成假逻辑。每件的指标、候选变更与恢复接口必须经过实际模型检查。

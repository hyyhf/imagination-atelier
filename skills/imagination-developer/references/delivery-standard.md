# 成品的深度与重复使用

不按按钮、文件体积、模型数量或自评分数决定完成度。找到当前题目不可省略的细节，在真实任务中检验。

- 用自己的材料开始，哪些对象和原始信息会保留？
- 改尺寸、顺序、样式、条件或规则时，哪些结果会一起变？
- 不符合条件的对象怎样定位、修正并保留原数据？
- 导出后能否用于原本的下一步，还是仍须手工重做？
- 同样方法做第二项时，哪些设置能复用，哪些数据应清空？

**三维与工程：**真实单位、厚度、连接、零件身份、遮挡、表面材质和可操作范围；导入与内部样例走同一流程。部件有用途明确的结构细节。剖切切到实际几何，爆炸视图可回到装配位置，测量依照模型，不能写死数值。

**二维设计：**完整轮廓、路径与图层，精确输入和直接编辑统一；裁切、拼接、版心、余量和导出按真实比例。画面与输出遵守同一设计，不用装饰图冒充有效纸样或尺寸图。

**文本与记录：**保留原内容、字段和顺序；编辑和审校能追踪原位置，逐项决定可撤回。导出不丢换行、引号、空值和特殊字符，不用固定摘要代替实际处理。

**排程与模拟：**时间、数量、依赖、容量和可用性一致；移动对象后相关约束重算，冲突可以解释和定位。启发式结果可继续修订，不能暗自删掉需求或把无法满足的任务标成已完成。

**媒体与视觉：**输入真实素材，裁切点、时间、声音与预览一致；输出是真实媒体，尺寸与格式明确。镜头、材质和构图变动进入最终图像；不能用封面图冒充可操作的三维产品。

**学习与开放体验：**足够的内容、可观察的关系、能区分变化的反馈和探索空间，不因题材是教学或艺术就交一个孤立滑块。

## 快速做第二项

保留制作方法，替换制作材料。按任务提供规则预设、素材替换、复制对象、批量应用、情景副本或快捷键。区分“新任务”和“恢复初始示例”；不要重新要求用户配置全部规则。

用两份材料试一次：两项结果来自各自输入，第一项数据不能意外串入第二项。跨页面继续时实际保存并回读，而不是只检查序列化字符串。

## 淘汰案例

只有内置对象、主要操作是调镜头、替换内容后能力消失、成果仍需手抄，或装饰强于任务的作品，重做或退出示范集。直接名字和封面帮助理解，本身不能修复这些问题。不要为保住数量留下低标准例子。

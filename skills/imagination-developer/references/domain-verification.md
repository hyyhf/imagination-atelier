# 为关键结果选择独立判据

作品正确性取决于哪个机制，就检查哪个机制。通常选择 1–3 个有区分力的小例或边界即可；涉及明显损失成本时再扩展。以下是方法库，不是每个作品的必填功能。

| 类型 | 制作前明确 | 有用的独立核对 |
| --- | --- | --- |
| 几何、空间、设计编辑 | 单位、坐标、朝向、比例、可确认的原始尺寸 | 已知长度/角度/面积；图例、方向箭头、主视图和导出是否一致 |
| 科学、教学、模拟 | 方程或规则、初值、参数、时间与简化假设 | 零值、平衡点、解析解、守恒量、步长减半比较或已知极限 |
| 优化、规划 | 可行性约束、目标、损耗、精度与算法保证 | 独立核算守恒与计数；小规模穷举；下界与启发式结果分开说明 |
| 数据、比较 | 来源、单位、时间口径、缺失值与样本性质 | 手算小表、聚合分解、改变输入后的可解释变化、导出回导 |
| 文本、隐私、转换 | 识别范围、字符位置规则、显式决定与真实替换 | 重复片段、重叠范围、Unicode边界、误识别/漏识别、实际输出载荷 |
| 音频、图像、媒体 | 合成/素材来源、时长、采样或像素规格、设备前提 | 用独立读取器解码导出文件，核对长度、尺寸与非空内容；设备感受另测 |
| 游戏、训练 | 规则、胜负或开放目标、随机性、重开方式 | 相同种子复现、边界动作、状态转移与计分守恒、不可达或卡死场景 |
| 叙事、艺术、阅读 | 完整内容、节奏、路径事实、表达意图 | 完整阅读；不同路径的因果与时间核对；动作确实改变了应改变的内容 |

## 定量结果

写清输出是近似值、示意、模拟还是现实测量。约束满足与最优性是两件事：排得下不等于最省；小样本等于最优不等于全部最优。到达可证明下界时，只在该模型和目标内说明结论。

计算与展示分离时防止口径漂移。例如整球受光面积和投影圆盘亮区不是同一分母；原料总长、净料、产品、锯损和余料需要能对账。注释中的单位、坐标和朝向也参与核对。

实用规划同时验证几类约束：矩形或盒体的边界与相交，板材的锯缝和未排件，日程的先后与资源容量，清单的单位与库存抵扣。三维外观必须对应实际用于约束的尺寸；能显示体积百分比不等于已经排得下。可行贪心排程不称最晚或最优。日期输出检查跨日、跨年和实际时区语义，而不只检查格式样子。

数值算法的输出看起来平滑，不能证明稳定或准确。选择与应用相称的误差阈值；必要时改变步长、使用解析特例或检查不变量。保护上限触发时给真实截断范围，不插补伪数据或把数值失败当自然现象。

## 文本与条件内容

检测器需要公开覆盖范围，不能把“未检出”等同“没有私人信息”。脱敏检验应在真正导出的文本或文件上确认删除，而非仅检查视觉黑条。输入变化导致偏移失效时不得套用旧范围。

事实性回顾只能来自真实发生的操作与证据。对于故事，路由和结局可达性检查之外还需内容判断；一段文笔流畅的结尾可能仍错误引用了另一条路径的经历。

## 资料与测试的独立性

数学小例、文件解码器或参考资料应能挑战实现，而非调用同一函数得到相同结果。使用源代码中的真实核心逻辑进行运行检查；不要重新写一份正确算法，再把它的通过当作原作品通过。

需要专业或可能变化的事实时核对一手来源，记录链接和本作品采用的范围。引用支持模型，不自动证明实现。虚构数据标为示例；不凭空给出排名、精确还原或因果保证。

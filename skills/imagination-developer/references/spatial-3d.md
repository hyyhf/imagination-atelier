# 空间表达：不是给方块加阴影

先判断空间关系是否真有价值，再选择实现。优先成熟 Three.js 或适用的固定版本库，制作时预打包到本地文件；用户不需要安装 npm 或开服务器。版本、附加控制器与许可证必须匹配。

## 先形体，后显示

基于实际尺寸／领域量建立对象：厚度、开口、支撑、接缝和连接；部件需要细节时按真实用途建模。可控细节预算与适当层级。不要为微倒角改变碰撞、面积、采购或导出几何。

## 材质与照明

粗糙度和金属度基于材质，不把所有物体做成同一塑料。纹理尺度随模型单位正确处理；白点、曝光、阴影偏差与接触不能靠盲目调高对比解决。有条件使用环境照明预滤波、正确色彩管理与抗锯齿。画面级环境接触遮蔽只能加强邻近接触，不能冒充几何阴影或物理照度。

## 镜头与编辑

默认镜头看清核心关系，提供复位、缩放、平移、必要剖切。编辑拖动与相机旋转互斥。射线拾取明确遮挡和对象范围；不能隔墙随意选中。屏幕坐标转模型坐标使用同一矩阵和单位。触屏与指针丢失需要真实设备复验。

## 工作对象与成品

内置模型与导入模型走同一选择、单位、编辑、保存、测量和导出路径。模型含贴图和外部资源时，保留资源关系或提示缺失；不能只接受自制格式并把导入按钮当装饰。

选择成熟能力，例如 Three.js 的材质、环境、阴影、拾取、剖切、轨道控制与匹配的加载器。画面与高分辨率导出使用相同状态，改变尺寸时正确调整相机。

本 Skill 不再随附旧案例的小渲染器。已有作品的内嵌引擎属于历史实现；新作品重新选择技术，避免同一组基础几何、材质和工具条决定所有成果。

# 从任意行业推导任务能力

行业名不能替代任务。先看用户正在处理的对象与动作，再查该任务实际需要的单位、规则、内容和成果。

对象可能是空间与部件、文件与记录、图像与声音、人员与事件、设备与资源、规则与证据、路径与过程。动作可能是构建、修改、比较、选择、验证、组织、复用或体验。通常需要几种关系一起成立。

| 任务关系 | 对象中应保留什么 | 可能需要的能力 | 有价值的下游成果 |
|---|---|---|---|
| 构建与装配 | 尺度、连接、部件身份、位置 | 导入、精确编辑、拾取、吸附、剖切、分解、测量 | 可编辑方案、尺寸图、装配说明 |
| 内容制作 | 原始素材、版本、片段、样式 | 素材库、直接编辑、预览、对照、批量应用 | 真正的图像、音频、视频、排版文件 |
| 安排资源 | 数量、工序、时间、可用性、依赖 | 排程、拖动、冲突检查、情景比较 | 可执行的计划、清单、日历 |
| 数据处理 | 原值、类型、字段、来源 | 映射、清洗、合并、去重、规则流水线、异常定位 | 清洗结果、问题清单、可复用规则 |
| 审核判断 | 原内容、证据、差异、决定 | 逐项比较、接受或撤回、标注、筛选 | 最终稿、差异报告、决定记录 |
| 理解与探索 | 条件、模型、过程、对照基准 | 直接改变、观察、测量、复现、比较 | 可复现的实验与记录 |
| 叙事与体验 | 内容、场景、行为、节奏 | 组织真实素材、路径、反馈、播放与回看 | 有完整内容的可分享作品 |

这些是推导维度，不是限定种类。科研、医疗行政、法律文本、制造、农业、零售、教育、影视、软件或个人生活中的对象可能同时落在几行；不要因此声称掌握全部行业专业规则。

专业数据结构、单位、计算方法、文件格式和真实业务约束不确定时，查官方规范或主要来源。依据用户提供的规则实现，缺失规则用明确的可编辑假设；不能把自行编写的启发式称作行业认证或专业结论。

让规则成为可用对象。例如交期、班次、尺寸余量、预算、命名方式、数据匹配键或文档审校规则，都应在它确实影响结果时可改、可保存、可追溯。

“省掉重复劳动”：找出材料经过哪些处理、哪些规则能复用，用代表性材料实现完整流程。
“把它弄清楚”：找到能区分解释的变量、证据与过程，让用户改变、比较和留下记录。
“做出这个效果”：识别核心对象和内容关系，取得或制作精细资源，让用户真实调整并输出成果。
“特别的体验”：定义具体内容、行为和节奏，让体验自身完整；不用空场景或随机效果代替创作。
